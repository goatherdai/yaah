Lists the MCP servers configured for this session and the tools each exposes. For every server it reports the name, transport, connection status, any startup error, the executable (never its arguments — resolved arguments routinely carry credentials), and a credential-scrubbed URL (no userinfo or query string). Tool names appear in the <server>_<tool> form used on the session tool surface, listing only what is registered and callable in this session; tools a server exposes that the session does not register are reported only as unregistered_tool_count. The roster is live session state — unlike `yaah mcp list`, which knows only the configuration. No parameters required.
